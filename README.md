# 🎯 AromaMatch AI Platform

An elegant, minimalist content-based recommendation engine built with Python and Streamlit. AromaMatch AI analyzes perfume profiles to discover and curate cross-brand olfactory alternatives based on geometric similarity vector patterns and unsupervised pattern clustering (K-Means).

## ✨ Features
* **Premium Minimalist UI:** Built with a clean, wide-grid "ethereal" luxury aesthetic.
* **Intelligent Data Pipeline:** Automated dataset column mapping to completely eliminate processing KeyErrors.
* **Curated Recommendation Matrix:** Instantly displays side-by-side alternative fragrance matches matching your scent profile category.
* **Machine Learning Backend:** Leverages TF-IDF vectorization and unsupervised learning algorithms for precision grouping.
